# 🚀 API Connect - MVP

## 🎯 Objetivo
A API Connect é um Produto Mínimo Viável (MVP) desenvolvido para atender às necessidades iniciais de uma startup de tecnologia. O objetivo principal do sistema é fornecer uma base sólida, estruturada sob os preceitos da arquitetura RESTful, para o gerenciamento completo de usuários (operações de CRUD). A aplicação foca na separação de responsabilidades (SoC), validação de entrada de dados e padronização rigorosa de respostas e códigos de status HTTP.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python 3
* **Microframework:** Flask
* **Persistência de Dados:** Manipulação dinâmica de arquivo estático (`.json`) simulando banco de dados.
* **Geração de Chaves:** Biblioteca nativa `uuid` (UUIDv4) para chaves primárias imutáveis.
* **Testes de API:** Thunder Client (VS Code)
